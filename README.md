# flask-contact-manager
Flask Contact Management REST API with SQLite database and CSV migration

## Features

- Add, view, update, and delete contacts
- REST API built using Flask
- SQLite database for storing contacts
- CSV migration support
- Contact management system

## Technologies Used

- Python
- Flask
- SQLite
- HTML/CSS
